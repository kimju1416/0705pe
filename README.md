단일 HTML 슬라이드 덱입니다.

## 사용법
- **이동**: 화면 좌/우 클릭, 방향키(← →), 모바일 스와이프
- **목차**: `O` 키 또는 하단 카운터 클릭
- **전체화면**: `F` 키
- 특정 슬라이드로 바로 가기: URL 뒤에 `#3` (예: 3번째 슬라이드)

## 구성
- 3번째 슬라이드: **바이브코딩 연수 성취기준** (상·중·하 성취수준)
- PART 01 바이브코딩 기초 · PART 02 왜 필요한가 · PART 03 실제로 만든 것들 · PART 04 지금 바로 만드는 법 · PART 05 그래도, 체육은 체육이다
